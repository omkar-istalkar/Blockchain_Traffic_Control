# 🚦 Decentralized Traffic Control & Emergency Vehicle Priority System

This project implements a **smart traffic management system** designed to improve urban mobility and emergency response. It **detects emergency vehicles**, dynamically creates **green corridors** using **adaptive traffic signal control**, and securely **logs all events on a blockchain** to ensure tamper-proof record-keeping.  

A **dashboard** provides operators with **real-time monitoring** of traffic conditions, alerts, and blockchain logs, offering complete visibility into system operations.
